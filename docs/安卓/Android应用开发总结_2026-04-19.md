## 一、项目概述

### 1.1 项目背景
本毕业设计项目聚焦智能门铃的核心需求，以 Android APP 为客户端，开发集人脸识别、访客登记、异常预警于一体的访客管理系统。系统既能够自动识别家庭成员并快速响应，又能记录陌生访客信息，为居家安全提供保障。

## 五、API 接口实现

### 5.1 认证接口
- `POST /api/auth/login` - 登录
- `POST /api/auth/register` - 注册
- `POST /api/auth/refresh` - 刷新 Token
- `GET /api/auth/me` - 获取用户信息

### 5.2 家庭接口
- `GET /api/family/list` - 获取家庭列表
- `GET /api/family/detail/{familyId}` - 家庭详情

### 5.3 访客接口
- `GET /api/visitor/list` - 访客列表
- `GET /api/visitor/{visitorId}` - 访客详情
- `GET /api/visitor/statistics` - 统计数据
- `GET /api/visitor/today` - 今日访客

### 5.4 成员接口
- `GET /api/member/list` - 成员列表
- `POST /api/member/add` - 添加成员
- `DELETE /api/member/{memberId}` - 删除成员

### 5.5 设备控制接口
- `POST /api/control/unlock` - 开锁
- `POST /api/control/alert` - 警报
- `POST /api/control/speak` - 语音
- `POST /api/control/snapshot` - 抓拍
- `GET /api/device/status` - 设备状态

### 5.6 报警接口
- `GET /api/alert/list` - 报警列表
- `POST /api/alert/handle` - 处理报警

## 六、架构设计

### 6.1 分层架构
```
┌─────────────────────────────────────────┐
│           UI Layer (Activity/Fragment)   │
├─────────────────────────────────────────┤
│           Repository Layer               │
│    (Auth / Visitor / Member / Command)   │
├─────────────────────────────────────────┤
│           Network Layer                  │
│         (Retrofit + OkHttp)              │
├─────────────────────────────────────────┤
│           Data Models                    │
│    (Request / Response DTOs)             │
└─────────────────────────────────────────┘
```

### 6.2 数据流
```
UI → Repository → Network → API Server
                     ↓
              Local Storage (Token)
```

### 6.3 关键设计模式
- **单例模式**: RetrofitClient, MyApp
- **Repository 模式**: 数据访问抽象层
- **观察者模式**: LiveData / Flow (待实现)
- **适配器模式**: RecyclerView.Adapter

## 九、已知问题

### 9.1 警告信息
```
w: Opt-in requirement marker androidx.compose.material3.ExperimentalMaterial3Api is unresolved.
```
**原因**: build.gradle.kts 中配置了 Compose 的 opt-in，但项目未使用 Compose
**解决**: 可以移除该配置，不影响功能

### 9.2 构建配置警告
```
The option setting 'android.defaults.buildfeatures.buildconfig=true' is deprecated.
```
**原因**: AGP 8.13 废弃该配置
**解决**: 已在 build.gradle.kts 中使用 `buildFeatures { buildConfig = true }` 替代
