# 陌生人停留检测与系统锁定功能实现日志

## 实现日期：2026-04-01

---

## 一、功能需求

1. **陌生人停留 30 秒检测**：当陌生人在摄像头前停留超过 30 秒时触发报警
2. **系统锁定**：触发报警后系统停止识别并锁定
3. **保存可疑人脸**：自动保存陌生人照片到指定文件夹
4. **主人解锁**：只有主人（nongfei）可以通过人脸识别解除锁定

---

## 二、实现细节

### 2.1 数据结构新增

```python
# 陌生人停留追踪
self.unknown_first_detect_time = None  # 首次检测时间
self.system_locked = False  # 系统锁定状态

# 主人身份（可解除锁定）
self.owner_name = "nongfei"

# 可疑人脸保存目录
self.suspicious_dir = '/home/aaa/graduation/data/faces/suspicious_persons'
```

### 2.2 核心函数

#### `_save_suspicious_face(frame, face_box)`
保存可疑人脸照片
- 裁剪人脸区域
- 以时间戳命名：`suspicious_YYYYMMDD_HHMMSS.jpg`
- 保存到 `suspicious_persons` 文件夹

#### `_lock_system(reason)`
锁定系统
- 设置 `system_locked = True`
- 停止识别循环 `running = False`
- 触发蜂鸣器长鸣报警 3 秒

#### `_unlock_system(name)`
解除系统锁定
- 仅当主人识别成功时调用
- 重置所有陌生人追踪状态
- 恢复系统运行

### 2.3 陌生人处理流程

```
陌生人出现
    ↓
记录首次检测时间
    ↓
持续检测并计算停留时间
    ↓
2 秒内连续检测 → 计数器 +1
    ↓
计数≥3 → 蜂鸣器长鸣 1 秒
    ↓
停留≥30 秒 → 保存人脸照片 → 锁定系统 → 长鸣 3 秒
    ↓
等待主人识别解锁
```

### 2.4 主人解锁流程

```
系统锁定状态
    ↓
有人出现在摄像头前
    ↓
人脸识别
    ↓
是主人 (nongfei)?
    ├─ 是 → 播放提示音 → 解锁系统 → 恢复正常运行
    └─ 否 → 保持锁定状态
```

```python
# 记录首次出现时间
if self.unknown_first_detect_time is None:
    self.unknown_first_detect_time = current_time
    logger.warning(f"[陌生人] 开始停留计时...")

# 计算停留时间
stay_duration = current_time - self.unknown_first_detect_time
logger.warning(f"[陌生人] 已停留 {stay_duration:.1f} 秒")

# 超过 30 秒锁定系统
if stay_duration >= 30.0:
    self._save_suspicious_face(frame, face['box'])
    self._lock_system("陌生人停留超过 30 秒")
```

```python
if result['is_known']:
```

## 六、测试场景

### 场景 1：陌生人短暂停留（<30 秒）
**预期**：
- 2 秒内连续 3 次检测 → 蜂鸣器长鸣 1 秒
- 陌生人离开 → 重置计时
- 系统保持正常运行

### 场景 2：陌生人停留超过 30 秒
**预期**：
- 保存可疑人脸照片
- 蜂鸣器长鸣 3 秒
- 系统锁定，停止识别
- 显示锁定画面

### 场景 3：系统锁定后主人出现
**预期**：
- 主人识别成功
- 蜂鸣器短鸣提示
- 系统解锁，恢复运行
- 步进电机开锁动作

### 场景 4：系统锁定后陌生人出现
**预期**：
- 识别为陌生人
- 保持锁定状态
- 不触发额外报警
