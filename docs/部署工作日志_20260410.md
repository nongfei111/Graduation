## 重要命令参考

### 服务器管理

```bash
# 查看服务状态
ps aux | grep python3

# 查看日志
tail -f /opt/doorbell/logs/server.log

# 重启服务
pkill -f doorbell_server.py
nohup python3 /opt/doorbell/doorbell_server.py > /opt/doorbell/logs/server.log 2>&1 &

# 查看端口
netstat -tlnp | grep 5000
```
