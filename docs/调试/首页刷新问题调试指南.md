# 首页刷新问题调试指南

## 问题描述
登录后首页一直刷新，无法正常显示。

## 已添加的日志

我已在以下文件中添加了详细的日志输出：

### 1. LoginActivity.kt
- `onCreate`: 记录登录状态检查
- `doLogin`: 记录登录过程和结果
- 标签：`SmartDoorbell.Login`

### 2. MainActivity.kt
- `onCreate`: 记录 Activity 创建
- `setupBottomNavigation`: 记录底部导航选择
- `loadFragment`: 记录 Fragment 加载
- 标签：`SmartDoorbell.Main`

### 3. HomeFragment.kt
- `onViewCreated`: 记录 Fragment 创建和初始化
- `loadStatistics`: 记录统计数据加载
- `loadServerStatistics`: 记录服务器统计加载
- `loadDeviceStatus`: 记录设备状态加载
- 标签：`SmartDoorbell.Home`

## 如何获取日志

### 方法一：使用 Android Studio（推荐）
1. 打开 Android Studio
2. 点击底部 "Logcat" 标签
3. 在搜索框输入：`SmartDoorbell`
4. 清除之前的日志（点击垃圾桶图标）
5. 在手机上重新登录并观察首页
6. 复制所有日志输出

### 方法二：使用命令行
```bash
# 清除旧日志
adb logcat -c

# 过滤输出（显示所有 SmartDoorbell 标签的日志）
adb logcat -s "SmartDoorbell:*"
```

## 可能的问题点

1. **Token 无效**：服务器返回 401 未授权
2. **家庭 ID 为 -1**：登录时未成功保存家庭 ID
3. **API 返回错误**：统计或设备接口返回错误
4. **Fragment 重复创建**：某些异常导致 Activity 重启
