## 一、已完成的优化

### 1.1 陌生人三次识别不通过长鸣报警

**需求**：当系统连续 3 次检测到陌生人脸时，触发蜂鸣器长鸣 1 秒报警

**实现代码**：
```python
# 陌生人追踪状态
self.unknown_face_count = 0
self.last_unknown_face_time = 0
self.unknown_alert_triggered = False

# 陌生人检测逻辑
if result['is_known']:
    # 识别成功，重置计数
    self.unknown_face_count = 0
    self.unknown_alert_triggered = False
else:
    # 2 秒内连续检测到陌生人才计数
    if (current_time - self.last_unknown_face_time) < 2.0:
        self.unknown_face_count += 1
    else:
        self.unknown_face_count = 1
    self.last_unknown_face_time = current_time

    # 三次识别不通过，触发长鸣报警
    if self.unknown_face_count >= 3 and not self.unknown_alert_triggered:
        self.buzzer.beep(1.0)  # 长鸣 1 秒
        self.unknown_alert_triggered = True
        self.unknown_face_count = 0  # 重置计数
```

**触发条件**：
- 2 秒内连续 3 次检测到陌生人脸
- 报警后自动重置，可再次触发

## 二、系统改进建议

### 2.1 识别阈值优化（重要）

**问题**：测试中发现识别置信度波动大（5%-38%），导致无法触发 `is_known` 条件

**原因**：`recognizer.py` 中阈值设置为 0.6（dlib 默认），但测试中置信度最高 only 38%

**建议修改**：
```python
# 方案 1：降低全局阈值（在 recognizer.py 第 41 行）
self.threshold = 0.5  # 原为 0.6，降低以提高识别灵敏度

# 方案 2：添加可配置的阈值
# 在 config/settings.py 中添加：
FaceRecognitionConfig.RECOGNITION_THRESHOLD = 0.5

# 方案 3：使用动态阈值调整
# 根据环境光线条件自动调整
```

### 2.2 人脸数据采集优化

**问题**：只有一张测试图片，导致识别稳定性差

**建议**：
1. 为 nongfei 采集更多人脸数据（建议 10-20 张）
2. 覆盖不同角度（正面、左侧、右侧）
3. 覆盖不同光线条件（白天、晚上）
4. 使用 `register_faces.py` 脚本批量注册

```bash
# 运行人脸注册脚本
python3 register_faces.py
```

### 2.3 步进电机控制优化

**当前问题**：
- 开锁速度固定，无法根据场景调整
- 无堵转检测

**建议**：
1. 添加开锁速度配置（通过配置文件或 GUI）
2. 添加电流检测判断堵转
3. 添加开锁失败重试机制

### 2.4 蜂鸣器提示音优化

**当前状态**：
- 成员识别：双声短鸣（0.15 秒×2）
- 陌生人报警：长鸣 1 秒

**建议增加**：
- 上锁成功提示音（单声短鸣）
- 系统错误提示音（三声急促鸣叫）
- 夜间模式（晚上关闭提示音）

### 2.5 陌生人处理优化

**当前实现**：三次识别不通过长鸣 1 秒

**建议增强**：
1. **拍照存档**：自动保存陌生人照片到数据库
2. **延时报警**：陌生人在门口停留超过 30 秒触发报警
3. **远程推送**：通过 WiFi 推送消息到手机 APP
4. **多次来访记录**：同一陌生人多次来访标记为"可疑人员"

### 2.6 性能优化

**当前 FPS**：8-9 FPS（640x480 分辨率）

**优化方向**：
1. 进一步降低分辨率（480x360）
2. 使用 TensorRT 加速推理
3. 多线程处理（识别和显示分离）

### 2.7 用户体验优化

1. **语音播报**：添加 TTS 语音（"欢迎回家"、"陌生人，请离开"）
2. **门铃按钮**：添加物理门铃按钮，按下时推送通知
3. **夜视模式**：添加红外补光灯，支持夜间识别
4. **离线模式**：无网络时本地存储，网络恢复后同步
