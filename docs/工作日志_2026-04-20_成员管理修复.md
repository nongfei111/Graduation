### 2.3 服务器 SQL 修复

**文件**: `cloud_server/server/app.py`

#### 问题 1: 访客列表 `family_id` 字段不存在

**原因**: `visitors` 表设计时没有 `family_id` 字段

**修复**: 通过 `LEFT JOIN` 从 `devices` 和 `families` 表关联获取

```python
query = f'''
    SELECT v.id, v.device_id, v.visitor_type, v.member_name,
           v.photo_path, v.photo_data, v.confidence, v.停留_duration as duration,
           v.created_at, d.user_id, f.id as family_id
    FROM visitors v
    LEFT JOIN devices d ON v.device_id = d.device_id
    LEFT JOIN families f ON d.user_id = f.owner_id
    WHERE {where_clause}
    ORDER BY v.created_at DESC
    LIMIT %s OFFSET %s
'''
```

#### 问题 2: SQL 字段歧义

**原因**: `WHERE` 子句中 `device_id` 没有表别名

**修复**: 添加表别名 `v`
```python
where_clause += f' AND v.device_id IN ({",".join(["%s"] * len(device_ids))})'
```

#### 问题 3: `is_alert` 字段不存在

**原因**: `visitors` 表没有 `is_alert` 和 `alert_reason` 字段

**修复**: 
- 移除 `is_alert` 过滤条件
- 返回数据中使用默认值
```python
visitor_list.append({
    ...
    'is_alert': False,  # 默认值
    'alert_reason': None,
})
```

## 七、技术总结

### 7.1 Retrofit Multipart 请求
- `@Multipart` 注解必须添加到包含 `@Part` 参数的接口
- 否则报错：`@Part parameters can only be used with multipart encoding`

### 7.2 ConstraintLayout 布局
- 多个视图垂直排列时使用链式约束
- 注意避免约束冲突导致视图重叠

### 7.3 MySQL 多表查询
- 使用表别名避免字段歧义
- `LEFT JOIN` 用于获取关联数据
- 注意字段在哪个表中存在
