# CLAUDE 智能门铃系统

> 基于树莓派的人脸识别智能门铃 - 毕业设计项目

## 项目概述

本系统是一个集人脸识别、访客管理、远程通信、手机 APP 控制于一体的智能门铃系统，运行在树莓派嵌入式平台上，支持云端数据同步和 Android 手机远程控制。

## 功能特性

## 快速开始

### 1. 服务器部署（阿里云）

```bash
# 安装依赖
cd server/
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件配置 MySQL、密钥等

# 启动服务器（开发环境）
python app.py

# 生产环境使用 Gunicorn + Nginx（见部署指南）
```

### 2. 树莓派配置

```bash
# 修改服务器地址
nano config/settings.py
# SERVER_HOST = "your-ecs-ip"

# 运行主程序
python main.py
```

### 3. Android APP

1. 使用 Android Studio 打开 `app/` 目录
2. 修改 `util/Constants.kt` 中的 `BASE_URL`
3. 编译运行

## API 接口

### 认证
- `POST /api/auth/register` - 用户注册
- `POST /api/auth/login` - 用户登录
- `POST /api/auth/refresh` - 刷新 Token

### 设备
- `POST /api/device/heartbeat` - 设备心跳
- `POST /api/device/upload/visitor` - 上传访客
- `POST /api/device/upload/batch` - 批量上传

### 访客
- `GET /api/visitor/list` - 访客列表
- `GET /api/visitor/statistics` - 统计数据

### 控制
- `POST /api/command/unlock` - 远程开锁
- `POST /api/command/reboot` - 远程重启

详见：[部署指南](DEPLOYMENT_GUIDE.md)

## 常见问题

**Q: 服务器无法访问？**
A: 检查阿里云安全组是否开放 80 端口，检查 Gunicorn 是否运行。

**Q: 树莓派连接失败？**
A: 检查服务器地址配置，使用 `ping` 测试网络连通性。

**Q: Android APP 网络错误？**
A: 确保 `AndroidManifest.xml` 添加了网络权限，服务器地址正确。
