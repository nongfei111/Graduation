## 三、技术架构

### 3.1 整体架构

```
┌─────────────────┐      HTTPS       ┌─────────────────┐      轮询        ┌─────────────────┐
│   树莓派设备     │◄────────────────►│   阿里云服务器   │◄───────────────►│  Android APP    │
│  (边缘端)       │                   │  (Flask+MySQL)  │                  │  (用户端)        │
├─────────────────┤                   ├─────────────────┤                  ├─────────────────┤
│ - 人脸识别      │  - 访客数据       │ - RESTful API    │  - 访客列表      │ - 访客查看      │
│ - 本地控制      │  - 心跳保持       │ - JWT 认证       │  - 统计数据      │ - 远程开锁      │
│ - 数据同步      │  - 控制命令       │ - 文件存储       │  - 图片加载      │ - 成员管理      │
│ - 离线缓存      │                   │                  │                  │                  │
└─────────────────┘                   └─────────────────┘                  └─────────────────┘
```

### 3.2 技术栈

| 模块 | 技术 | 版本 |
|------|------|------|
| 树莓派 | Python | 3.11+ |
| 人脸识别 | OpenCV + face_recognition | 最新 |
| 服务器 | Flask + MySQL | 2.3+ / 8.0+ |
| Android | Kotlin | 1.9+ |
| 网络请求 | Retrofit2 | 2.9.0 |
| 图片加载 | Glide | 4.16.0 |
| 数据存储 | Room | 2.6.1 |

### 3.3 核心算法

**人脸识别流程**:
1. 人脸检测（Haar Cascade / CNN）
2. 人脸对齐（关键点检测）
3. 特征提取（FaceNet / ArcFace）
4. 特征比对（欧氏距离 / 余弦相似度）

**识别阈值**:
- 相似度阈值：0.6（可配置）
- 响应时间：< 1 秒（本地）
