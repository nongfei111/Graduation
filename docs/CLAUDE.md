
# CLAUDE.md

CLAUDE智能门铃系统设计与实现
一、项目概述
1.1 项目背景
传统门铃仅具备单一呼叫功能，无法实现访客身份核验与记录，难以满足现代居家安全管理需求。随着嵌入式技术与计算机视觉的发展，人脸识别凭借非接触式、高精度的优势，成为智能门禁与门铃系统的核心技术。嵌入式端本地部署人脸识别算法，能避免云端传输带来的隐私泄露风险与网络延迟问题，适配居家场景的安全与实时性需求。
1.2 项目目标
本毕业设计聚焦智能门铃的核心需求，以低成本嵌入式设备为载体，开发集人脸识别、访客登记、异常预警于一体的访客管理系统。该系统既能够自动识别家庭成员并快速响应，又能记录陌生访客信息，为居家安全提供保障。
二、系统设计
2.1 硬件平台搭建
核心控制模块： 树莓派4B或Jetson Nano
图像采集模块： 树莓派官方摄像头
交互与预警模块： 5-7英寸触摸屏、5V无源蜂鸣器,步进电机（模拟开锁）
辅助硬件： 16GB及以上Micro SD卡、5V 3A电源适配器

三、核心技术实现
3.1 人脸数据集构建
家庭成员数据集： 3-5人，每人采集50-80张不同角度、光线的人脸图像
陌生访客数据集： 采集公开人脸数据集子集或模拟访客采集
预处理流程： 图像灰度化、人脸检测裁剪、去噪、尺寸归一化
3.2 轻量级人脸识别算法
算法选型： MTCNN+SVM组合、简化版FaceNet或ArcFace
优化策略： 模型量化、裁剪等手段精简模型体积
部署方案： 通过TensorFlow Lite或OpenCV将优化后的模型部署到嵌入式端
四、系统功能模块
4.1 人脸采集与识别模块
● 实时捕获门口画面
● 自动检测人脸并匹配数据库
● 支持家庭成员增删改查
4.2 访客管理模块
● 识别家庭成员时自动记录开门时间
● 识别陌生访客时抓拍图像并存储访客信息
● 建立临时档案系统
4.3 交互与预警模块
● 显示屏显示识别结果
● 家庭成员识别成功可联动模拟门锁提示
● 陌生访客停留超设定时间触发蜂鸣器轻报警
4.4 数据同步模块
● 通过WiFi将访客记录同步至手机APP
● 支持本地小型数据库存储
● 方便用户回看历史记录

5.1 嵌入式硬件平台
5.2 算法训练与部署
在PC端使用PyTorch或TensorFlow完成模型训练与验证，并通过模型量化、剪枝等技术进行优化。最终利用TensorFlow Lite、LibTorch或OpenCV的DNN模块，将优化后的模型部署到嵌入式设备，实现本地实时人脸特征提取与比对。
六、系统测试与优化
6.1 测试环境
在室内门口、楼道等不同光照场景下测试系统性能，针对识别准确率低、延迟高、误报警等问题优化。
6.2 优化策略
● 调整人脸检测阈值
● 补充特定光线场景的训练样本
● 优化算法推理流程
● 改进访客预警逻辑
6.3 性能指标
● 识别准确率：≥95%
● 响应时间：≤1秒
● 误报率：≤5%
● 系统延迟：≤500ms
