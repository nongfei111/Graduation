## 代码实现

### gpio_control.py 修改

```python
class Buzzer:
    """蜂鸣器控制（支持无源蜂鸣器）"""
    
    BUZZER_FREQUENCY = 2000  # 2kHz
    
    def __init__(self, pin=26, buzzer_type='passive', frequency=None):
        self.pin = pin
        self.buzzer_type = buzzer_type
        self.frequency = frequency or self.BUZZER_FREQUENCY
        self.handle = lgpio.gpiochip_open(0)
        
    def beep(self, duration=0.15):
        """无源蜂鸣器 PWM 鸣叫"""
        if self.buzzer_type == 'passive':
            lgpio.tx_pwm(self.handle, self.pin, self.frequency, 50, 0)
            time.sleep(duration)
            lgpio.tx_pwm(self.handle, self.pin, 0, 0, 0)
```

### test_touchscreen_optimized.py 修改

```python
# 初始化蜂鸣器
self.buzzer = Buzzer(buzzer_type='passive')

# 识别成功时鸣叫
if result['is_known']:
    current_time = time.time()
    # 3 秒内不重复鸣叫
    if result['name'] != self.last_recognized_name or \
       (current_time - self.last_recognize_time) > 3.0:
        self.buzzer.beep(0.15)
        self.last_recognized_name = result['name']
        self.last_recognize_time = current_time
```

## 问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 蜂鸣器不响 (GPIO 17) | 接线错误 | 改为 GPIO 26 |
| 蜂鸣器不响 (第一次) | GND 接错位置 | 重新连接 GND |
| PWM 错误 "bad PWM dutycycle" | duty_cycle 参数范围错误 (应为 0-100%) | 改为 50 (50%) |
| 无源蜂鸣器需要频率 | 与有源蜂鸣器控制方式不同 | 使用 `tx_pwm` 发送方波 |

## 测试结论

### 成功经验
1. **无源蜂鸣器需要 PWM 驱动**: 使用 `lgpio.tx_pwm()` 发送 2kHz 方波
2. **占空比 50%**: 产生对称方波，声音最大
3. **频率选择**: 2kHz 声音清晰，适合提示音
4. **防重复鸣叫**: 避免同一人连续识别时嘈杂

### 系统性能
- 人脸识别 FPS: ~12 (640x480 分辨率，每 3 帧检测一次)
- 蜂鸣器响应延迟: <100ms
- CPU 占用: 正常
