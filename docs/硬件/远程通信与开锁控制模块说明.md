## 快速开始

### 1. 配置服务器信息

编辑 `config/settings.json`:

```json
{
  "network": {
    "server_host": "8.134.196.56",
    "server_port": 5000,
    "mqtt_broker": "broker.emqx.io",
    "mqtt_port": 1883
  }
}
```

### 2. 安装依赖

```bash
pip install paho-mqtt requests flask flask-cors
```

### 3. 运行测试

```bash
# 运行完整测试
python tests/test_server_connection.py

# 测试远程开锁（模拟模式）
python remote_comm.py --simulator --test
```

### 4. 启动远程通信服务

```bash
# 树莓派上运行（真实硬件）
python remote_comm.py

# 开发测试（模拟硬件）
python remote_comm.py --simulator
```

## 功能特性

### 4.1 MQTT 通信

- ✅ 连接到公共 MQTT Broker (broker.emqx.io)
- ✅ 订阅开锁指令主题 (`doorbell/unlock`)
- ✅ 发布设备状态主题 (`doorbell/status`)
- ✅ 自动重连机制
- ✅ 消息统计

### 4.2 远程开锁

- ✅ 步进电机控制 (28BYJ-48)
- ✅ 支持模拟模式（无硬件测试）
- ✅ 开锁回调函数
- ✅ 开锁结果通知

### 4.3 数据同步

- ✅ 访客记录上传
- ✅ 访问日志上传
- ✅ 离线缓存
- ✅ 断点续传

### 4.4 API 接口

服务器端提供以下接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/unlock` | POST | 远程开锁 |
| `/api/status` | GET | 设备状态查询 |
| `/api/info` | GET | 服务器信息 |
| `/api/health` | GET | 健康检查 |

## 使用示例

### 示例 1: 发送开锁指令（curl）

```bash
curl -X POST http://8.134.196.56:5000/api/unlock \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "user123",
    "method": "app"
  }'
```

### 示例 2: 使用 Python 发送开锁指令

```python
import requests
import json

url = "http://8.134.196.56:5000/api/unlock"
data = {
    "user_id": "user123",
    "method": "app"
}

response = requests.post(url, json=data)
print(response.json())
```

### 示例 3: 使用 MQTT 发送开锁指令

```python
import paho.mqtt.client as mqtt
import json

client = mqtt.Client()
client.connect("broker.emqx.io", 1883, 60)

message = {
    "action": "unlock",
    "user_id": "user123",
    "timestamp": "2026-04-10T12:30:00"
}

client.publish("doorbell/unlock", json.dumps(message))
client.disconnect()
```

### 示例 4: 集成到主程序

```python
from src.sync.remote_unlock import create_remote_unlock_controller

# 创建控制器
controller = create_remote_unlock_controller(use_simulator=True)

# 设置回调
def on_unlock(user_id, timestamp, method):
    print(f"开锁：用户={user_id}, 方式={method}")

controller.set_unlock_callback(on_unlock)

# 启动（后台模式）
controller.start(blocking=False)

# 等待指令
import time
try:
    while True:
        time.sleep(1)
except KeyboardInterrupt:
    controller.stop()
```

## MQTT 主题说明

### 订阅主题（设备端）

| 主题 | 用途 | 消息格式 |
|------|------|----------|
| `doorbell/unlock` | 开锁指令 | `{"action":"unlock","user_id":"xxx"}` |

### 发布主题（设备端）

| 主题 | 用途 | 消息格式 |
|------|------|----------|
| `doorbell/status` | 设备状态 | `{"device_id":"xxx","status":"online"}` |
| `doorbell/visitor` | 访客通知 | `{"type":"visitor","data":{...}}` |
| `doorbell/alert` | 报警通知 | `{"type":"alert","data":{...}}` |

## 故障排查

### 问题 1: MQTT 连接失败

```bash
# 检查网络
ping broker.emqx.io

# 检查端口
telnet broker.emqx.io 1883

# 安装 MQTT 库
pip install paho-mqtt
```

### 问题 2: 步进电机不转

```bash
# 检查 GPIO 权限
gpioinfo

# 检查 lgpio 库
pip list | grep lgpio

# 使用模拟模式测试
python remote_comm.py --simulator --test
```

### 问题 3: API 接口无法访问

```bash
# 检查服务器状态
curl http://8.134.196.56:5000/api/health

# 检查防火墙（阿里云控制台）
# 确保端口 5000 已开放
```
