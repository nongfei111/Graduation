#### 项目特点

1. **架构模式**: MVVM + Repository 模式
2. **网络请求**: Retrofit + OkHttp + Coroutines
3. **本地存储**: EncryptedSharedPreferences + Room
4. **图片加载**: Glide
5. **依赖注入**: 手动依赖注入（Application 级）
6. **UI 组件**: Material Design 3
7. **异步处理**: Kotlin Coroutines + Flow
