## 关键问题与结论

- 远程命令延迟约 30 秒：
  - 根因：命令主要通过设备心跳轮询拉取，默认 30s。
  - 方案：将 `HEARTBEAT_INTERVAL` 默认改为 2s；并启用 MQTT 命令通道作为主通道。
- MQTT 启动失败：
  - 根因：缺少 `paho-mqtt` 依赖（`No module named 'paho'`），导致只能回退心跳轮询。
  - 解决：在树莓派虚拟环境安装 `paho-mqtt`；系统 python 受 PEP668 限制，用 apt 安装 `python3-paho-mqtt`。
- 摄像头无画面、卡欢迎界面：
  - 常见根因：同时运行多个 `main.py` 抢占摄像头（以及 GPIO/电机），或取帧偶发失败后缺少自恢复。
  - 解决：强制单实例运行；主循环增加取帧失败自恢复（自动 release + 重建 Camera）；启动脚本补齐 `XAUTHORITY`。
- 远程抓拍依赖 onnxruntime 导致失败：
  - 根因：旧 `snapshot` 实现引用 `src.core.camera`，在树莓派环境缺 `onnxruntime`。
  - 解决：改为从主程序最新帧抓拍并直接上传到 `/api/visitor/upload`，不依赖 onnxruntime。
