### 1. 修复登录后首页无限刷新/崩溃问题

**问题定位**：
- 通过 logcat 日志分析，发现 `HomeFragment.loadServerStatistics()` 发生 `NullPointerException`
- 根本原因：服务器 `/api/stats` 接口返回格式与客户端期望格式不匹配
  - 服务器返回：`{"success": true, "stats": {...}}`
  - 客户端期望：`{"success": true, "data": {"summary": {...}}}`

**修复内容**：
- 修改 `cloud_server/server/app.py` 中的 `/api/stats` 接口
- 返回符合客户端期望的格式：
  ```json
  {
    "success": true,
    "data": {
      "period": {"days": 7, "from": "", "to": ""},
      "summary": {
        "total_visitors": 0,
        "member_visits": 0,
        "stranger_visits": 0,
        "alert_count": 0,
        "today_visitors": 0
      },
      "daily_stats": []
    }
  }
  ```

**验证结果**：
- 服务器重启后，App 登录不再崩溃
- 首页正常显示

## 技术总结

### 问题排查方法
1. **查看 logcat 日志**：过滤应用标签，查找崩溃堆栈
2. **分析网络请求**：OkHttp 日志拦截器显示请求/响应内容
3. **对比接口格式**：服务器返回 JSON vs 客户端期望的数据结构

### 常见错误模式
- **NullPointerException**: Gson 反序列化失败，字段为 null
- **422 Unprocessable Entity**: JWT Token 格式错误（Not enough segments）
- **Address already in use**: 端口被占用，需 `pkill -9 python` 清理

### 服务器部署注意事项
1. 修改代码后先备份：`cp app.py app.py.bak`
2. 强制杀死进程：`pkill -9 python`
3. 等待端口释放：`sleep 2-3`
4. 后台启动：`python app.py &`
5. 查看日志：`tail -f` 或检查 `/var/log`
