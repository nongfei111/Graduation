#### 问题 2：家庭 ID 获取逻辑

**问题描述**：
多个 Fragment 中使用 `familyId == -1` 判断是否已选择家庭，但登录后 `familyId` 初始值为 -1，需要调用 API 获取家庭列表并设置。

**修复内容**：
1. 在 `AuthRepository` 中添加 `loadFamilyId()` 方法：
```kotlin
suspend fun loadFamilyId(): Result<Int> {
    return try {
        val token = preferencesManager.getAuthHeader() ?: return Result.failure(Exception("未登录"))
        val response = apiService.getFamilies(token)
        if (response.isSuccessful) {
            val data = response.body()?.data
            if (data != null && data.families.isNotEmpty()) {
                val familyId = data.families.first().id
                preferencesManager.familyId = familyId
                Result.success(familyId)
            } else {
                Result.failure(Exception("没有家庭信息"))
            }
        } else {
            Result.failure(Exception("获取家庭列表失败"))
        }
    } catch (e: Exception) {
        Result.failure(e)
    }
}
```

2. 更新 `LoginActivity` 的 `doLogin` 方法，在登录成功后自动获取家庭 ID：
```kotlin
result.onSuccess { loginData ->
    // 登录成功后，获取家庭 ID
    val familyResult = authRepository.loadFamilyId()
    if (familyResult.isFailure) {
        Toast.makeText(this@LoginActivity, "获取家庭信息失败", Toast.LENGTH_SHORT).show()
    }
    Toast.makeText(this@LoginActivity, "登录成功", Toast.LENGTH_SHORT).show()
    navigateToMain()
    finish()
}
```

**文件修改**：
- `app/src/main/java/com/example/smartdoorbell/data/repository/Repositories.kt`
  - 添加 `loadFamilyId()` 方法
- `app/src/main/java/com/example/smartdoorbell/ui/login/LoginActivity.kt`
  - 更新 `doLogin` 方法
