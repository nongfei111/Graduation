## 二、问题原因分析

### 2.1 添加成员姓名带引号
**原因**: Retrofit 的 `@Part("name") name: String` 会将字符串序列化为 JSON 格式，加上引号。

**解决方案**: 使用 `RequestBody` 发送纯文本：
```kotlin
// API 接口
@Part("name") name: okhttp3.RequestBody

// Repository 调用
val nameBody = name.toRequestBody("text/plain".toMediaType())
apiService.addMember(token, familyId, nameBody, photoPart)
```

### 2.2 删除成员返回 HTML 错误
**原因**: 服务器端 `delete_member` 函数使用普通 cursor 而不是 `DictCursor`，导致 `member['family_id']` 访问元组时报错，触发异常返回 HTML 错误页面。

**解决方案**: 
```python
cursor = conn.cursor(pymysql.cursors.DictCursor)
```

### 2.3 上传照片失败
**原因**: 服务器端 `update_member_photo` 函数同样使用普通 cursor 而不是 `DictCursor`。

**解决方案**: 
```python
cursor = conn.cursor(pymysql.cursors.DictCursor)
```

### 2.4 添加成员显示失败
**原因**: 可能是响应解析问题或网络超时。服务器实际已添加成功，但客户端未收到正确响应。

## 八、技术总结

### 8.1 Retrofit Multipart 请求
- `@Part("field") value: String` 会将字符串序列化为 JSON，加上引号
- 正确做法：使用 `RequestBody` 发送纯文本
```kotlin
val body = value.toRequestBody("text/plain".toMediaType())
@Part("field") fieldBody: RequestBody
```

### 8.2 PyMySQL DictCursor
- 普通 cursor 的 `fetchone()` 返回元组：`('value1', 'value2')`
- DictCursor 的 `fetchone()` 返回字典：`{'field1': 'value1', 'field2': 'value2'}`
- 必须指定 `pymysql.cursors.DictCursor` 才能使用字典方式访问

### 8.3 Flask 异常处理
- 异常未捕获时会返回 HTML 错误页面
- 确保所有数据库操作都有 try-except-finally 块
- finally 块中检查连接状态再关闭
