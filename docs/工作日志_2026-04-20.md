## 一、问题描述

### 1.1 Android APP 问题
根据用户反馈和截图，发现以下问题：

## 二、问题根因分析

### 2.1 Gradle 版本不匹配
| 组件 | 原版本 | 问题 |
|------|--------|------|
| AGP (Android Gradle Plugin) | 8.13.0 | 版本过高，与 Gradle 不兼容 |
| Gradle | 8.13 | 导致资源打包失败 |

**现象**：Android Studio 显示 `'gradle-wrapper.properties' not found`，编译时资源文件未正确打包到 APK 中

### 2.2 服务器端 SQL 字段错误
```python
# 错误代码（第 1360 行）
cursor.execute(
    'INSERT INTO users (username, password, is_active) VALUES (%s, %s, 1)',
    (name, hashed)
)

# 数据库表结构
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,  # 字段名是 password_hash 不是 password
    ...
)
```

### 2.3 空数据处理不当
- 访客列表为空时，客户端返回错误而非空数据结构
- 成员列表为空时，显示"获取失败"而非友好提示

### 2.4 服务器端口被 systemd 服务占用
```bash
systemctl list-units --type=service | grep doorbell
# 输出：smart-doorbell.service  loaded active running
```

## 九、技术总结

### 9.1 Gradle 版本兼容性
| AGP 版本 | 所需 Gradle 版本 | JDK 版本 |
|----------|------------------|----------|
| 8.7.0 | 8.7+ | 17-21 |
| 8.13.0 | 8.13+ | 17-21 |

**建议**：使用稳定版本组合 AGP 8.7.0 + Gradle 8.9

### 9.2 常见问题排查
1. **资源文件未打包**：检查 Gradle 版本兼容性，执行 Clean + Rebuild
2. **端口被占用**：使用 `lsof -i :端口` 或 `netstat -tlnp | grep 端口` 查找进程
3. **SQL 字段不匹配**：检查数据库表结构与代码中的字段名
