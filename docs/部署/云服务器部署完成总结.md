## 三、快速部署步骤

### 步骤 1: 登录服务器
```bash
ssh root@8.134.196.56
```

### 步骤 2: 上传项目文件
```bash
# 方式 1: 使用 scp
scp -r * root@8.134.196.56:/home/smart_doorbell/

# 方式 2: 使用 Git
git clone <your-repo-url> /home/smart_doorbell
```

### 步骤 3: 执行一键部署脚本
```bash
chmod +x cloud_server_setup.sh
./cloud_server_setup.sh
```

### 步骤 4: 初始化数据库
```bash
mysql -u root -p < database/init_mysql.sql
```

### 步骤 5: 配置环境变量
```bash
cd /home/smart_doorbell
cp cloud_server/.env.example .env
vim .env  # 修改配置项
```

### 步骤 6: 启动服务
```bash
# 配置 systemd 服务
cp cloud_server/smart-doorbell.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable smart-doorbell
systemctl start smart-doorbell

# 查看状态
systemctl status smart-doorbell
```
