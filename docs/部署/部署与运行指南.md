## 二、服务器端部署（阿里云 ECS）

### 2.1 环境要求

- Python 3.8+
- MySQL 8.0+
- Redis（可选，用于缓存）
- Nginx（反向代理）

### 2.2 安装步骤

#### 步骤 1: 安装依赖

```bash
# 登录阿里云 ECS（Ubuntu 20.04）
ssh root@your-ecs-ip

# 安装 Python 和 MySQL
sudo apt update
sudo apt install python3-pip python3-dev mysql-server nginx -y

# 进入项目目录
cd /var/www/smart-doorbell/server

# 安装 Python 依赖
pip3 install -r requirements.txt
```

#### 步骤 2: 配置 MySQL 数据库

```bash
# 登录 MySQL
mysql -u root -p

# 创建数据库和用户
CREATE DATABASE smart_doorbell CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'doorbell'@'localhost' IDENTIFIED BY 'your-strong-password';
GRANT ALL PRIVILEGES ON smart_doorbell.* TO 'doorbell'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

#### 步骤 3: 配置环境变量

创建 `.env` 文件：

```bash
# server/.env
FLASK_ENV=production
SECRET_KEY=your-secret-key-change-in-production
JWT_SECRET_KEY=your-jwt-secret-key

# MySQL 配置
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=doorbell
MYSQL_PASSWORD=your-strong-password
MYSQL_DATABASE=smart_doorbell

# Redis 配置（可选）
REDIS_HOST=localhost
REDIS_PORT=6379

# 阿里云 OSS（可选）
OSS_ENABLED=false
OSS_ENDPOINT=oss-cn-hangzhou.aliyuncs.com
OSS_ACCESS_KEY_ID=your-access-key
OSS_ACCESS_KEY_SECRET=your-access-secret
OSS_BUCKET_NAME=smart-doorbell
```

#### 步骤 4: 启动服务器

开发环境（测试用）:
```bash
cd /var/www/smart-doorbell/server
python3 app.py
# 访问 http://localhost:5000/api/health
```

生产环境（Gunicorn + Nginx）:
```bash
# 安装 Gunicorn
pip3 install gunicorn

# 创建 systemd 服务
sudo nano /etc/systemd/system/doorbell.service
```

服务配置内容:
```ini
[Unit]
Description=Smart Doorbell Flask Server
After=network.target

[Service]
User=www-data
Group=www-data
WorkingDirectory=/var/www/smart-doorbell/server
ExecStart=/usr/bin/python3 -m gunicorn -c - -w 4 -b 127.0.0.1:5000 app:app

[Install]
WantedBy=multi-user.target
```

启动服务:
```bash
sudo systemctl start doorbell
sudo systemctl enable doorbell
sudo systemctl status doorbell
```

#### 步骤 5: 配置 Nginx

```bash
sudo nano /etc/nginx/sites-available/doorbell
```

Nginx 配置:
```nginx
server {
    listen 80;
    server_name your-domain-or-ip;

    # 日志
    access_log /var/log/nginx/doorbell-access.log;
    error_log /var/log/nginx/doorbell-error.log;

    # 客户端上传文件大小限制
    client_max_body_size 16M;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用配置:
```bash
sudo ln -s /etc/nginx/sites-available/doorbell /etc/nginx/sites-enabled
sudo nginx -t
sudo systemctl restart nginx
```

#### 步骤 6: 配置防火墙

```bash
# 允许 HTTP/HTTPS
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 如果使用 HTTPS（推荐）
# 安装 Certbot
sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d your-domain.com
```

## 六、常见问题

### Q1: 服务器无法访问

**检查**:
1. 阿里云安全组是否开放 80 端口
2. Gunicorn 是否运行：`systemctl status doorbell`
3. Nginx 日志：`tail -f /var/log/nginx/doorbell-error.log`

### Q2: 树莓派连接失败

**检查**:
1. 服务器地址是否正确
2. 树莓派网络是否正常：`ping your-ecs-ip`
3. 防火墙是否允许：`sudo ufw status`

### Q3: Android APP 网络错误

**检查**:
1. `AndroidManifest.xml` 是否添加网络权限
2. 服务器地址是否正确
3. HTTP 明文传输：`android:usesCleartextTraffic="true"`

### Q4: 数据库连接失败

**解决**:
```bash
# 检查 MySQL 状态
sudo systemctl status mysql

# 检查用户权限
mysql -u doorbell -p -e "SHOW DATABASES;"
```

## 七、后续优化建议

1. **HTTPS 加密**: 使用 Let's Encrypt 免费证书
2. **Redis 缓存**: 缓存热点数据（统计数据、访客列表）
3. **图片 CDN**: 使用阿里云 OSS + CDN 加速图片加载
4. **消息推送**: 集成小米/华为推送（国内）或 Firebase FCM（海外）
5. **监控告警**: 配置 Prometheus + Grafana 监控服务器状态
