## 三、成员管理 API 修复

### 3.1 问题一：添加成员成功但数据库无数据

**症状**：
- API 返回添加成功
- 数据库 `members` 表为空

**原因**：
- `add_member()` 函数中 `use_members_table` 分支缺少 `conn.commit()` 和 `conn.close()`
- 事务未提交，数据未持久化

**修复**：
```python
# 添加 commit 和 close
conn.commit()
conn.close()

return jsonify({...}, 201)
```

### 3.2 问题二：成员列表返回错误

**症状**：
- API 返回 `tuple indices must be integers or slices, not str`
- 无法获取成员列表

**原因**：
- `get_member_list()` 使用 `cursor.cursor()` 创建的是普通游标
- `fetchall()` 返回元组而非字典
- 代码尝试用字典方式访问元组数据 (`m['id']`)

**修复**：
```python
# 使用 DictCursor
cursor = conn.cursor(pymysql.cursors.DictCursor)
```
