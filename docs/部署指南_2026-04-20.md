1. 登录后点击底部导航栏「成员」
2. 点击右下角「+」悬浮按钮
3. 输入成员姓名（如：爸爸、妈妈）
4. 点击确定

1. 在成员列表中找到刚添加的成员
2. 点击「上传照片」按钮
3. 从相册选择一张人脸照片
4. 等待上传完成

### 3.4 删除成员
1. 点击成员项的删除按钮（垃圾桶图标）
2. 确认删除

## 四、关键技术点

### 4.1 成员管理设计
- **新设计**: 成员直接存储在 `members` 表，不需要先注册用户
- **旧设计**: 成员需要先注册用户，再关联到家庭（已废弃）

### 4.2 照片存储
- **服务器路径**: `/home/smart_doorbell/server/uploads/members/`
- **数据库**: `members.face_image` (BLOB) + `members.face_image_path` (路径)

### 4.3 API 接口
| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/member/list` | GET | 获取成员列表 |
| `/api/member/add` | POST | 添加成员（支持照片上传） |
| `/api/member/{id}/delete` | DELETE | 删除成员 |
| `/api/member/{id}/photo` | PUT | 更新成员照片 |

## 五、常见问题

### Q1: 登录失败
**A**: 检查服务器是否运行，访问 http://8.134.196.56:5000/api/health

### Q2: 成员列表为空
**A**: 先添加成员，确保 family_id 正确

### Q3: 上传照片失败
**A**: 检查网络权限，确保 APP 有存储权限

### Q4: 服务器端口被占用
**A**: SSH 登录服务器执行 `pkill -9 python` 后重启
