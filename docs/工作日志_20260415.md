## 八、编译与运行

### 8.1 环境要求
- Android Studio Arctic Fox 或更高版本（推荐 Android Studio Hedgehog）
- JDK 11 或更高版本
- Gradle 7.6.3+
- Android Gradle Plugin 7.4.2+

### 8.2 编译步骤

#### 方法一：使用 Android Studio（推荐）
```
1. 启动 Android Studio
2. File -> Open -> 选择 C:\Users\HP\Desktop\graduation\app 目录
3. 等待 Gradle 同步完成
4. Build -> Build Bundle(s) / APK(s) -> Build APK(s)
5. APK 生成在 app/build/outputs/apk/debug/app-debug-apk
```

#### 方法二：使用命令行
```bash
# 设置 JAVA_HOME
set JAVA_HOME=C:\Program Files\Microsoft\jdk-11.0.16.101-hotspot

# 编译 Debug APK
cd C:\Users\HP\Desktop\graduation
gradlew.bat :app:assembleDebug

# APK 位置：app/build/outputs/apk/debug/app-debug.apk
```

### 8.3 配置说明
- `build.gradle` (项目级) - 依赖配置，AGP 7.4.2
- `app/build.gradle` - 应用级配置
- `settings.gradle` - Maven 镜像配置
- `gradle.properties` - JDK 11 配置

### 8.4 注意事项
1. 系统环境变量 JAVA_HOME 可能与配置冲突，请确保使用 JDK 11+
2. 首次编译需要下载 Gradle 和依赖，请保持网络连接
3. 如遇到网络问题，配置文件中已使用阿里云/腾讯云镜像源
