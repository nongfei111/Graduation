## 二、已完成工作

### 2.1 硬件层实现

#### 步进电机配置
- **型号**: 28BYJ-48 减速步进电机
- **驱动板**: ULN2003 步进电机驱动板
- **GPIO 连接**:
  - IN1 → GPIO 1 (BCM 编号)
  - IN2 → GPIO 7
  - IN3 → GPIO 8
  - IN4 → GPIO 25

#### 激励模式
采用**半步模式（8 拍）**，相比单相激励具有以下优势：
- 旋转更平滑，减少机械振动
- 噪音更低
- 步距角减半（0.08789°）
- 每转步数：2048 步（减速后）

### 2.2 软件层实现

#### gpio_control.py 模块

实现了三个核心类：

1. **`Buzzer` 类** - 蜂鸣器控制
   - 支持无源/有源蜂鸣器
   - PWM 方波驱动（2kHz，50% 占空比）
   - 短鸣、双声鸣叫、报警长鸣等方法

2. **`StepperMotor` 类** - 步进电机控制
   - 半步模式激励序列
   - 正/反转控制
   - 开锁/上锁动作封装（90 度旋转）
   - 可调速旋转（step_delay 参数）

3. **`DoorbellController` 类** - 门铃控制器
   - 统一管理蜂鸣器和电机
   - `on_member_recognized()` - 家庭成员识别成功联动
   - `on_unknown_visitor()` - 陌生访客检测
   - `trigger_alarm()` - 触发报警

#### main.py 主程序集成

修改内容：
```python
# 1. 导入 DoorbellController
from gpio_control import DoorbellController

# 2. 初始化门铃控制器
self.doorbell_controller = DoorbellController()

# 3. 家庭成员识别成功时联动
self.doorbell_controller.on_member_recognized(result['name'])
# → 触发蜂鸣器双声短鸣 (0.3 秒)
# → 触发步进电机开锁 (顺时针 90 度，约 1 秒)

# 4. 系统关闭时清理资源
self.doorbell_controller.cleanup()
```

## 四、遇到的问题及解决

### 问题 1：电机抖动不旋转
**现象**: 通电后电机抖动但不转动  
**原因**: 激励序列错误，使用了整步 4 拍而非半步 8 拍  
**解决**: 修改为半步激励序列（8 拍模式）

### 问题 2：识别成功后重复开锁
**现象**: 连续帧导致同一人识别时重复触发开锁  
**原因**: 视频流每秒处理 10+ 帧，每帧都触发  
**解决**: 添加 5 秒防重复触发机制

### 问题 3：电机转速过快失步
**现象**: 转速过快时电机失步、噪音大  
**原因**: step_delay 设置过小（0.001 秒）  
**解决**: 调整为 0.002 秒，平衡速度和稳定性
