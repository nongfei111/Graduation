## 二、问题分析和修复

### 2.1 删除成员返回 404

**原因**: Android API URL 路径不匹配
- Android: `DELETE /api/member/{memberId}`
- 服务器：`/api/member/{memberId}/delete`

**修复**: 修改 Android ApiService
```kotlin
// 修改前
@DELETE("/api/member/{memberId}")

// 修改后
@DELETE("/api/member/{memberId}/delete")
```

### 2.2 照片不显示

**原因 1**: 服务器返回的是本地路径而不是 HTTP URL
```
uploads/members/member_3_5_20260420162940.jpg
```

**修复**: 服务器端转换为完整 URL
```python
face_image_url = m['face_image_path']
if face_image_url:
    # 路径格式：/home/smart_doorbell/server/uploads/members/xxx.jpg
    # 转换为：http://8.134.196.56:5000/uploads/members/xxx.jpg
    face_image_url = "http://8.134.196.56:5000/" + face_image_url.replace("/home/smart_doorbell/server/", "")
```

**原因 2**: Android Adapter 从本地文件加载而不是 URL
```kotlin
// 修改前 - 检查本地文件
if (!photoPath.isNullOrEmpty() && File(photoPath).exists()) {
    Glide.with(context).load(File(photoPath))...
}

// 修改后 - 从 URL 加载
val imageUrl = if (photoUrl.startsWith("http")) {
    photoUrl
} else {
    "http://8.134.196.56:5000${photoUrl.replace("/home/smart_doorbell/server", "")}"
}
Glide.with(context).load(imageUrl)...
```

### 2.3 成员名字带引号

**原因**: Retrofit `@Part` 将 String 序列化为 JSON

**修复**: 使用 RequestBody 发送纯文本
```kotlin
// API 接口
@Part("name") name: okhttp3.RequestBody

// Repository
val nameBody = name.toRequestBody("text/plain".toMediaType())
```

### 2.4 添加成员显示失败

**原因**: 服务器响应格式问题或网络超时

**修复**: 已修复响应格式，确保正确返回 JSON

## 七、问题总结

### 7.1 为什么之前的问题没解决？
1. **服务器代码修改后没重启** - 修改 app.py 后需要 `pkill -9 python` 并重启
2. **APK 没安装新版本** - 需要卸载旧 APP 安装新 APK

### 7.2 重要提示
- 每次修改服务器代码后必须**重启服务**
- 每次修改 Android 代码后必须**重新编译安装**
- 服务器返回的 URL 必须是**完整 HTTP URL**
